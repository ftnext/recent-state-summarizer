# Project background

- The project started as a tool that collects all article titles from sources such as a Hatena Blog archive for a given period and passes them to an LLM to summarize the author’s recent activity.
- A later use case was to import the collected URLs into NotebookLM in bulk.
- Current development focuses on extending the fetch functionality to extract every URL from a single web page supplied as input. The existing LLM summarization feature has seen few additions.
